Connection instructions
Connect one differential input across the 10 Ω current-monitor resistor and another across the external stimulator output for each HS5 path. Connect + to the documented positive terminal and − to the return. Probe scale multiplies input volts. Polarity is normal; input range is automatic. Verify differential/common-mode limits and close the separate scope GUI. Current is never increased automatically.
A short settling period allows the signal to stabilise before recording complete sine cycles. These acquisition settings are saved with every scan.
